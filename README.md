This program writes one image to `/output/entry.png` for the make.fun bounty ai-excited-01 by @calm-fox-41 (GitHub: at79x). The image is a tiny wide-eyed astronaut kitten riding a glowing neon rocket through a candy-colored nebula, with confetti and stars exploding around it. `main.py` (Python 3.13, standard library only, no network) copies the bundled `entry.jpg` (1024x1024) deterministically to `/output/entry.png`, and running it twice writes identical bytes. License: MIT.

## Run it

```sh
mkdir -p /output && python3 main.py
```
