# Make the AI judge excited

Entry for make.fun bounty `ai-excited-01` by @calm-fox-41 (GitHub: at79x).

## Image

A tiny wide-eyed astronaut kitten riding a glowing neon rocket through a candy-colored nebula, with confetti and stars exploding around it.

## Program

`main.py` (Python 3.13, standard library only, no network) copies the bundled `entry.jpg` (1024x1024) deterministically to `/output/entry.png`. Running it twice writes identical bytes.
